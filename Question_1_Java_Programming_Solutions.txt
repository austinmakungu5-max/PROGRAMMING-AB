Q1.1.1 – Develop a Java application

Develop a Java application to generate a sales report for a local
company specialising in mattress sales. The report should summarise the
total sales for the company’s three top-performing products over three
months.

The application must calculate and display: - The total number of
products sold. - The average number of products sold per product. - The
most popular product based on the highest total sales.

Sample data: Product Month 1 Month 2 Month 3 Cozy Nights Monarch 25 18
20 Restonic Barbados 15 10 12 Sealy Phukek 18 15 20

In your implementation, use both single and two-dimensional arrays to
develop the product sales report for the business.

Create a class called Product that includes distinct methods for
obtaining the total products sold, calculating the average products
sold, and determining the most popular product. The Product class must
implement an IProducts interface.

Create a public interface called IProducts containing the following
methods:

public interface IProducts {

    int GetTotalProductsSold();

    double GetAverageProductSold();

    String GetMostPopularProduct();

}

Additionally, create a class named PrintProduct that is responsible for

PART 2: SOLUTIONS

1.  CREATE THE IProducts INTERFACE

Create a Java file called IProducts.java.

public interface IProducts {

    int GetTotalProductsSold();

    double GetAverageProductSold();

    String GetMostPopularProduct();

}

2.  CREATE THE Product CLASS

Create a file called Product.java. This class stores the product names
and sales figures. It calculates the total, average and most popular
product.

public class Product implements IProducts {

    private String[] productNames;
    private int[][] sales;

    public Product(String[] productNames, int[][] sales) {
        this.productNames = productNames;
        this.sales = sales;
    }

    @Override
    public int GetTotalProductsSold() {

        int total = 0;

        for (int i = 0; i < sales.length; i++) {
            for (int j = 0; j < sales[i].length; j++) {
                total += sales[i][j];
            }
        }

        return total;
    }

    @Override
    public double GetAverageProductSold() {

        int total = GetTotalProductsSold();
        int count = 0;

        for (int i = 0; i < sales.length; i++) {
            count += sales[i].length;
        }

        if (count == 0) {
            return 0;
        }

        return (double) total / count;
    }

    @Override
    public String GetMostPopularProduct() {

        int highestSales = -1;
        String popularProduct = "";

        for (int i = 0; i < sales.length; i++) {

            int productTotal = 0;

            for (int j = 0; j < sales[i].length; j++) {
                productTotal += sales[i][j];
            }

            if (productTotal > highestSales) {
                highestSales = productTotal;
                popularProduct = productNames[i];
            }
        }

        return popularProduct;
    }

}

3.  CREATE THE PrintProduct CLASS

Create a file called PrintProduct.java.

public class PrintProduct {

    private Product product;

    public PrintProduct(Product product) {
        this.product = product;
    }

    public void PrintTotalProductSales() {

        System.out.println("TOTAL PRODUCT SALES: "
                + product.GetTotalProductsSold());
    }

    public void PrintAverageProductSales() {

        System.out.println("AVERAGE PRODUCT SALES: "
                + product.GetAverageProductSold());
    }

    public void PrintMostPopularProduct() {

        System.out.println("MOST POPULAR PRODUCT: "
                + product.GetMostPopularProduct());
    }

    public void PrintReport() {

        System.out.println("\nPRODUCT SALES REPORT - 2026");
        System.out.println("*****************************");

        PrintTotalProductSales();
        PrintAverageProductSales();
        PrintMostPopularProduct();
    }

}

4.  CREATE THE Main CLASS

Create a file called Main.java.

import java.util.Scanner;

public class Main {

    public static void main(String[] args) {

        Scanner input = new Scanner(System.in);

        // Single-dimensional array
        String[] products = {
            "Cozy Nights Monarch",
            "Restonic Barbados",
            "Sealy Phukek"
        };

        // Two-dimensional array
        int[][] sales = new int[3][3];

        // Enter sales figures
        for (int i = 0; i < products.length; i++) {

            for (int j = 0; j < 3; j++) {

                System.out.print(
                    "Enter number of sales for month "
                    + (j + 1) + " for "
                    + products[i] + ": ");

                sales[i][j] = input.nextInt();
            }

            System.out.println();
        }

        // Create Product object
        Product product = new Product(products, sales);

        // Create PrintProduct object
        PrintProduct report = new PrintProduct(product);

        // Display report
        report.PrintReport();

        input.close();
    }

}
